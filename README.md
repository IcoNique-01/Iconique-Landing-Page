IcoNique – Jobs & Consulting Landing Page + Dashboard

This project is a two-page web application consisting of a Landing Page and a Dashboard.  
It is designed to showcase job listings, consulting services, and an admin-style dashboard for managing data.  

The goal of this project is to demonstrate front-end development skills in HTML, CSS, and JavaScript.

Features
- Landing Page
  - Responsive navigation bar with dropdown menus  
  - Hero section with job search functionality  
  - Preloader animation  
  - Login, Register, and Forgot Password modal forms  

- Dashboard
  - Responsive sidebar navigation  
  - Profile section with dynamic username (stored via `localStorage`)  
  - Dark mode toggle  
  - Data overview cards (reports, leads, tasks, etc.)  
  - Active orders table with styled rows  
  - Analytics section with chart display  
  - Preloader animation  

Technologies Used
- HTML5 – Structure and semantics  
- CSS3 – Styling, layout, animations, and responsiveness  
- JavaScript – DOM manipulation, localStorage, preloader logic, and UI interactivity
